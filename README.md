# Correos internos entre dos sedes

Proyecto integrador de tercer nivel de Ingeniería en Sistemas de Información.
Periodo académico: septiembre de 2026 a enero de 2027.

## Descripción

Una empresa de soluciones tecnológicas abrió una segunda sede y necesita comunicación institucional entre ambas. Seleccionamos un sistema de correos internos con bandeja de entrada, enviados, lectura y eliminación de mensajes entre usuarios registrados, sin correo externo ni SMTP.

El proyecto completo integrará una aplicación cliente-servidor en Go, autenticación FastAPI y una red con OpenWrt, VLAN y OSPF. Esta entrega corresponde únicamente a la fase 1: contexto, planificación y organización.
