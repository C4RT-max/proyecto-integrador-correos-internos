# Contrato de comunicación del equipo

**Integrantes:** Jose Martin Fuel, Kevin Almache y Felipe Montenegro.

Los tres integrantes confirmamos los siguientes acuerdos para desarrollar el proyecto.

## Canales de comunicación

Usaremos WhatsApp para la coordinación cotidiana, las consultas y los avisos de retrasos. GitHub servirá como respaldo de los documentos del proyecto. Tendremos dos reuniones semanales de aproximadamente 20 minutos, en un horario acordado entre los tres.

## Tiempos de respuesta

Procuraremos responder los mensajes de trabajo dentro de las 24 horas siguientes. Cuando un asunto sea urgente, se avisará por WhatsApp y se procurará responder dentro de cuatro horas, considerando la disponibilidad de cada integrante.

## Tareas y revisiones

Cada tarea tendrá un responsable que la revisará para comprobar que el documento esté correcto y tenga coherencia.

## Decisiones

Las decisiones se tomarán entre los tres integrantes.

## Conflictos y retrasos

Cada integrante procurará hablar con el resto del equipo para poder avisar al docente correspondiente el motivo del retraso y consultar si existen soluciones, como presentar el trabajo en otro lapso de tiempo.
